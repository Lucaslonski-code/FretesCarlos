## 📌 Sobre o projeto

**Carlos Fretes** é uma plataforma web criada para transformar o processo tradicional de solicitação de fretes em uma experiência simples e eficiente.

O projeto foi desenvolvido com foco em:

- comunicação clara com o cliente;
- experiência mobile-first;
- orçamento rápido através de um fluxo guiado;
- design moderno e amigável;
- facilidade de contato direto pelo WhatsApp.

A proposta é permitir que o cliente informe os detalhes da sua mudança ou transporte em poucos passos e receba uma estimativa inicial de forma prática.

---

## ✨ Principais funcionalidades

### 🧮 Simulador inteligente de orçamento

Fluxo guiado em etapas para coletar:

- cidade e bairro de origem;
- cidade e bairro de destino;
- tipo de mudança;
- quantidade de ajudantes;
- características dos locais;
- preferência de turno.

Ao final, o usuário recebe uma estimativa inicial e pode continuar diretamente pelo WhatsApp.

---

### 📱 Experiência Mobile First

O projeto foi pensado principalmente para dispositivos móveis, garantindo:

- navegação simples;
- botões acessíveis;
- textos legíveis;
- formulário confortável;
- layout totalmente responsivo.

Compatível com:

- smartphones;
- tablets;
- desktops.

---

### 💬 Integração com WhatsApp

Após preencher o simulador, o cliente pode enviar sua solicitação diretamente pelo WhatsApp com uma mensagem organizada contendo os dados necessários para o atendimento.
